# HomeCare Passport

SaaS demo dành cho người dùng cá nhân để quản lý đồ dùng, bảo hành, lịch bảo dưỡng, sửa chữa và chi phí. Smart Assistant sử dụng playbook cục bộ và hoạt động hoàn toàn offline.

## Chạy local

```powershell
npm install
npm run dev
```

Mở `http://127.0.0.1:3002`. Dữ liệu demo được lưu trong localStorage.

## Kiểm thử

```powershell
npm run build
npm run test:e2e
```
